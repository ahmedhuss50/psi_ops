How the AI works

A specialist pipeline, not a single chatbot.

Each inbound message flows through a tuned two-model architecture — fast triage classifies, deep specialists extract.

Message Pipeline

From inbound text to structured operations data in <3 seconds

→ 1
Capture Webhook
Twilio routes inbound SMS/MMS to n8n. Message stored with sender, body, media URLs.
→ 2
Triage Haiku
Claude Haiku tags message type, extracts job numbers, fleet, customer, urgency in ~500ms.
→ 3
Specialist Sonnet
Parts orders and intakes route to dedicated Sonnet agents for deep line-item extraction.
→ 4
Match Catalog
Each line item fuzzy-matched against 15,751 parts using Postgres trigram similarity.
5
Persist Supabase
Structured data lands in jobs, intakes, parts extraction tables. Portal updates live.
⚡
